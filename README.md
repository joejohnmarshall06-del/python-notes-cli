# Python Notes CLI

A small command-line notes app that stores notes in a local JSON file.

## Run

```powershell
python notes.py add "Plan GitHub projects"
python notes.py list
python notes.py done 1
```

## Commands

- `add <text>`: add a note.
- `list`: show all notes.
- `done <id>`: mark a note as complete.
- `delete <id>`: delete a note.
